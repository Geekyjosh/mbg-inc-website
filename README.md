# MBG Inc

### Telecom, Mobility & IT Expense Management Website

**Live Website:** https://www.mbg-inc.com/

## Overview

MBG Inc is a business technology company focused on telecom, mobility and IT expense management solutions. The website provides information about the company's services, solutions and technology offerings through a responsive digital experience.

I worked on the project as a **Full-Stack Web Developer**, contributing across the frontend, backend, CMS, database integrations and production infrastructure.

## My Role

I was responsible for frontend development, backend functionality, WordPress CMS implementation, database integration, API connectivity and supporting production infrastructure.
